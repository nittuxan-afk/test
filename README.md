# 競馬予想プログラム 🏇

netkeiba のデータをスクレイピングし、スコアリングで予想順位を出力するツールです。

## スコアリング内訳（最大92点）

| 要素 | 最大点 | 説明 |
|------|--------|------|
| 単勝オッズ | 25点 | 人気馬ほど高スコア |
| 過去成績 | 30点 | 直近3走の着順を点数化 |
| 馬体重変化 | 10点 | 変化が少ないほど高スコア |
| コース適性 | 15点 | コース別の1人気率・最速率などを評価 |
| 血統適性 | 12点 | 「ちょっちゅ使える血統辞典2026」をもとに父・母父を評価 |

血統評価: 超絶買い(+12) / 激買い(+8) / 買い(+4) / 普通(0) / 注意(-3) / 消し(-6)


## 使い方

### CLIモード（推奨）

引数なしで起動すると対話形式でレースIDを入力できます。

```bash
python main.py
```

```
  競馬場コード: 01=札幌 02=函館 03=福島 04=新潟 05=東京
               06=中山 07=中京 08=京都 09=阪神 10=小倉
  形式: YYYY + 競馬場(2桁) + 開催回(2桁) + 日数(2桁) + R番号(2桁)

レースID (12桁) を入力してください: 202506050811
過去成績を取得しますか？ [Y/n]:
```

引数で直接指定することもできます。

```bash
# 通常モード（過去成績・血統あり）
python main.py --race-id 202506050811

# 高速モード（過去成績を取得しない）
python main.py --race-id 202506050811 --no-history
```

### Webモード

```bash
python app.py
```

ブラウザで `http://localhost:5000` を開いてレースIDを入力してください。

## レースID の形式

```
202506050811
^^^^          年 (2025)
    ^^        競馬場コード (06=中山)
      ^^      開催回 (05回)
        ^^    日数 (08日)
          ^^  レース番号 (11R)
```

netkeiba のレースページ URL から確認できます。  
例: `https://race.netkeiba.com/race/shutuba.html?race_id=202506050811`
